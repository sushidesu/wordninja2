# 良いお題ルーブリック v1

- 日付: 2026-06-27
- 対象: ワードニンジャのお題セット（**4語ちょうど**）
- 用途: 人間評価の基準 / 将来の自動評価ループ（`topic_set_evaluations.source = "rubric-v1"`）のプロンプト土台

## 根拠

設計議論と「整理後の実データ」から抽出した。

- お題は4語。核は「**似ているが区別できる**」。近すぎ＝同義で理不尽、遠すぎ＝無関係で自明。
- 距離（embedding 由来）と評価は別軸。本ルーブリックは**評価軸**を言語化したもの。
- 人評価 0.8 で残されたセット（＝良いお題の実例）:
  - サッカー / 水泳 / スキー / 野球 … テーマ「スポーツ」（球技・水・雪と多様）
  - ライオン / イルカ / トンボ / ティラノサウルス … テーマ「生き物」（哺乳類・海生・昆虫・恐竜）
  - 病院 / 学校 / 駅 / 老人ホーム … テーマ「施設」（医療・教育・交通・福祉）
- 編集の示唆: 動物候補を `ペンギン/ぞう` → `トンボ/ティラノサウルス` に変更 → **サブ種の多様性を最大化**する意図。
- 削除された低評価例: `温泉/サウナ/岩盤浴/銭湯`（温浴のみ）、`緑茶/紅茶/ほうじ茶/麦茶`（茶のみ）、`みかん/オレンジ/グレープフルーツ/レモン`（柑橘のみ）= 狭い1サブカテゴリで近すぎ。

→ 良いお題の形: **広く誰もが分かる共通テーマがあり、その中で各語が異なるサブ種から選ばれて互いに明確に区別できる4語**。「似ている」＝共通の括り、「区別できる」＝サブ種の多様性。

## 評価軸（重み付き合計 = 総合スコア 0.0〜1.0）

| # | 観点 | 重み | 1.0 | 0.5 | 0.0 |
|---|------|------|-----|-----|-----|
| C1 | 共通の括り（テーマ明確さ）＝「似ている」 | 0.20 | 誰もが一目で同じ仲間と分かる広いテーマ | 括りはあるが弱い／一部が外れ気味 | 共通の括りが無く無関係な寄せ集め |
| C2 | 多様性（区別のしやすさ）＝「区別できる」 | 0.30 | 4語すべて異なるサブ種。near-synonym 無し | 概ね多様だが2語が近い／同一サブ寄り | 同義語・同一サブカテゴリの重複が複数 |
| C3 | 距離の適正（似てるが区別できる） | 0.25 | 推理が成立する絶妙な塩梅 | やや簡単 or やや難（1語浮く／2語近い） | 近すぎ＝理不尽 or 遠すぎ＝自明 |
| C4 | 一般性・公平性 | 0.15 | 全語が広く知られた一般語 | 1語がやや専門的／世代差あり | 固有名詞・専門用語・マイナー語で理不尽 |
| C5 | 面白さ（質問の広がり） | 0.10 | 連想・質問の切り口が豊富で盛り上がる | 普通 | 単調で質問が広がらない |

総合 = Σ(重み × 各スコア)。各観点は 0.0/0.5/1.0 に限らず中間値も可。

## 失格・大幅減点条件（満たすと総合を強く下げる）

- 4語ちょうどでない
- 同義語・言い換えのペアを含む（近すぎ／理不尽）
- 共通の括りが無い（無関係な寄せ集め）
- 一般に知られない語（固有名詞・専門用語・極端なマイナー語）が混入

## スコア帯ガイド

- **0.9–1.0**: 括り明確＋4語が見事に異なるサブ種＋全語一般的＋推理が絶妙。文句なし。
- **0.7–0.85**: 良い。括りと多様性があり実戦投入可。（＝現状の登録3セット）
- **0.4–0.65**: 1語が浮く／2語が近い等の難あり。要編集。
- **0.0–0.35**: 括り無し or 同義語含む or マイナー語混入。不適格。

## 自動評価への落とし込み（次段）

LLM（または sub-agent）に本ルーブリックを渡し、各お題セットを C1–C5 で採点 → 重み付き総合を算出 → `topic_set_evaluations` に `source="rubric-v1"`, `score=総合`, `note=各観点の内訳` で書き込む。人評価（`source="human"`）とは別行で共存し、両者の差分で生成・膨張の方向と帯の校正に使う。

## 調整余地

- 重み（特に C2:0.30 / C3:0.25）はデータが増えたら人評価との相関で再校正。
- C5（面白さ）は主観が強く LLM 採点がブレやすい。重みを低め(0.10)に置いている。
