## 根拠（24ペアの人評価を分析）

高速評価の結果: 良い5 / 惜しい6 / ダメ13。

- 良い: ペンギン×ダチョウ, 自転車×ヘリコプター, 医者×消防士, お城×灯台, 桜×ひまわり
- 惜しい: ピアノ×ハープ, バイオリン×太鼓, 卓球×ボクシング, バスケ×弓道, 傘×手袋, りんご×かぼちゃ
- ダメ: うどん×パスタ, 馬×ラクダ, 雪×雨, 金槌×のこぎり, 電球×ろうそく, カエル×ヘビ, サメ×タコ, コーヒー×牛乳, 鉛筆×はさみ, 飛行機×船, 森×砂漠, 寿司×ハンバーガー, 時計×カレンダー

### 否定された仮説: 「近い=悪い / 遠い=良い」
- `ペンギン×ダチョウ`（同じ「飛べない鳥」で近い）は **良い**。
- `飛行機×船`（普通の距離）・`寿司×ハンバーガー`（遠い）は **ダメ**。
- → 距離は主軸ではない。

### 実際の判別軸: 共通点の「質（特定性・意外性）」
- **良い** = 2語は別物に見えるのに、**特定的で意外な共通点**で結びつく（飛べない鳥 / 人を助ける職業 / 季節を象徴する花 / ランドマーク的な高い建造物 / 乗り物の両極端）。
- **ダメ** = 共通点が「ただ同じジャンル」で**自明**（麺・工具・天気・乗り物・食べ物・海の生き物）。特に**同一サブカテゴリ＝近すぎ**は失格。
- **惜しい** = 共通点はあるが、やや自明 or やや近い（楽器・スポーツ・道具など、括りが普通）。

非対称性（近すぎは厳禁・遠さは許容）は維持: 近すぎは失格、遠さ自体は減点しない。問題になるのは「遠い」ことではなく「共通点が平凡/自明」なこと。

## 評価軸（重み付き合計 = 0.0〜1.0）

総合 = Σ(重み×各スコア)。C1 を最重視（最も識別力がある軸）。

## 失格条件（総合を強く下げる）
- 2語でない
- 近すぎ（同義・言い換え・同一サブカテゴリ）→ C2=0
- 固有名詞・専門用語・極端なマイナー語 → C4 を大きく下げる

## スコア帯と実例
- **0.85–1.0（良い）**: 別物＋意外で特定的な共通点。例 ペンギン×ダチョウ（飛べない鳥）, 医者×消防士（人を助ける）, 桜×ひまわり（季節の象徴）。
- **0.5–0.7（惜しい）**: 共通点はあるが普通の括り。例 ピアノ×ハープ, 卓球×ボクシング, 傘×手袋。
- **0.0–0.35（ダメ）**: 同一サブカテゴリ＝近すぎ、または「同じジャンル」だけの自明な並べ。例 うどん×パスタ, 飛行機×船, 寿司×ハンバーガー。

## 自動評価への含意
- 評価器の主タスクは「共通点が特定的・意外か、それとも自明なジャンル括りか」を判定すること（C1）。これは主観的でブレやすいので、**上記の良い/惜しい/ダメ実例を few-shot として評価プロンプトに同梱**し、**複数評価者の中央値**を取るのが望ましい。
- 近すぎ（C2=0）は機械的に弾きやすい（同義・同一サブカテゴリ判定）。embedding のペア距離が極端に小さいものを近すぎ候補として事前フィルタにも使える。

## 留保
- 24件からの推定。時計×カレンダー（やや特定的な共通点だがダメ）など境界例があり、軸は完全には綺麗でない。データが増えたら C1 の言語化と重みを再校正する。
