# 良いお題ルーブリック v3（ペア）

- 日付: 2026-06-27
- 対象: ワードニンジャのお題ペア（ちょうど2語）
- v2 からの変更: **「意外性」偏重を是正**。実評価で v2 は metaphor を良ペアと取り違えていた。

## 根拠（v2バッチ16ペアの人評価）

v2 は全ペアを 0.70〜0.96 と予測したが、人の判定は 16中14が没:

- 意味不明(5): カメレオン×信号機, 種×アイデア, ストロー×象の鼻, 時計の針×コンパス, 蜘蛛の巣×漁網
- 遠すぎ(5): 指紋×雪の結晶, 磁石×人気者, こだま×ブーメラン, 蝶×注射器, 鏡×湖
- 予測可能(3): 蛍×街灯, 年輪×地層, 鍵×パスワード
- 平凡(1): 砂時計×ダム
- 良い/惜しい(2): **ろうそく×氷**, **風船×潜水艦**

### 発見: 抽象・比喩で結ぶと「遠すぎ/意味不明」になる
- v2バッチは「意外な共通点」を狙い、**抽象的性質・比喩・機能アナロジー**（浮力/唯一無二/引き寄せる/色が変わる/返ってくる/吸う）に走った。v2評価器はこれを高 C1 と誤評価。
- 人にとってそれは遠すぎ/意味不明。生き残ったのは**具体的で一目で把握できる共通点**を持つ2つだけ（ろうそく×氷=溶ける, 風船×潜水艦=浮力）。
- 第1バッチの良ペア（ペンギン×ダチョウ=飛べない鳥, 医者×消防士=人を助ける職業, 桜×ひまわり=季節の花）は全て**具体的な同カテゴリ**だった。

### 結論: 良いペアの正体
**同じ“具体的なカテゴリ/属性”に属する別物**。共通点は一目で具体的に把握でき、かつ自明すぎない。意外性は「**同カテゴリ内のサブ種の違い**」から出す。**概念的飛躍・比喩から出してはいけない**。

「意外性」は3段階のバンドで捉える:
- 自明すぎ（うどん×パスタ=麺、砂時計×ダム）→ **平凡**
- ちょうどよい（ペンギン×ダチョウ=飛べない鳥）→ **良い**
- 抽象・比喩で飛躍（磁石×人気者=引き寄せる）→ **遠すぎ/意味不明**

## スコア帯と実例（人評価で確定）
- **良い（0.8+）**: 具体的な同カテゴリ×別サブ種。ペンギン×ダチョウ, 医者×消防士, 桜×ひまわり, お城×灯台, 自転車×ヘリコプター, ろうそく×氷。
- **惜しい（0.55–0.7）**: 具体的だがやや普通 or やや飛躍。風船×潜水艦, ピアノ×ハープ, 卓球×ボクシング。
- **遠すぎ/意味不明（〜0.3）**: 抽象・比喩で結ぶ。磁石×人気者, 種×アイデア, 指紋×雪の結晶, カメレオン×信号機, ストロー×象の鼻。
- **近すぎ/平凡/予測可能（〜0.3）**: うどん×パスタ, 砂時計×ダム, 鍵×パスワード。

## 生成への含意（重要）
- **狙うのは「具体的な同カテゴリの別サブ種」**。テンプレは第1バッチ（飛べない鳥/職業/花/建造物/乗り物）。
- **比喩・なぞなぞ・詩的連想・機能アナロジーは禁止**（v2バッチの失敗パターン）。「○○という性質が共通」で繋ぐのは避け、「どちらも△△（具体名詞カテゴリ）の一種」で繋ぐ。

## 評価器への含意
- 旧評価器は「巧妙さ/意外性」を褒め過ぎた。v3評価器は**抽象・比喩を見たら C1 を厳しく下げる**こと。判定の few-shot に今回の 遠すぎ/意味不明 実例を負例として同梱する。
- 近すぎ（C3）は embedding ペア距離で事前フィルタ可。抽象/比喩の検出は距離では難しく、評価器の主タスク。
